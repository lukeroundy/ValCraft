ValCraft

Play Minecraft inside Valheim: build with Minecraft blocks in your Valheim world, with shared items, sleep, fires and more.

Download

Windows installer (latest release) All releases & manual files

Current version: 0.15.1, for Minecraft 1.21.1 with NeoForge 21.1.259 and Valheim with BepInEx 5.4.23.x.

Install (Windows, Steam)

  1. Download ValCraft-Installer-0.15.1.exe and run it. SmartScreen may warn because the installer is unsigned: click More info, then Run anyway.
  2. The installer finds Valheim through Steam. If it can't, click Browse and select the folder that contains valheim.exe.
  3. If BepInEx is missing, the installer offers to download BepInExPack_Valheim from Thunderstore.
  4. Choose how to run Minecraft:
    • Portable Prism Launcher (recommended): installed to Documents\ValCraft\PrismLauncher with a ready ValCraft instance (NeoForge, 4 GB RAM, Java downloaded automatically).
    • Your own launcher (Prism, ATLauncher, CurseForge or the official launcher): the installer copies the mod into your mods folder and shows a setup guide.
  5. Click Install. When asked, log in to your Microsoft account in Prism (Log in now).
  6. Start Valheim. Minecraft starts and connects automatically. Load a world and play.

Updating, repairing, uninstalling

Run the newest installer and click Install / Repair. Your settings, item mappings and Minecraft worlds are kept. Check for updates looks for the latest GitHub release. Uninstall removes the plugin, and optionally the settings and the portable Prism.

Manual install

  1. Install BepInExPack_Valheim.
  2. Copy ValCraft.Valheim.dll to Valheim\BepInEx\plugins\ValCraft\.
  3. Create a Minecraft 1.21.1 / NeoForge 21.1.259 instance and put valcraft-0.15.1.jar in its mods folder.
  4. Set the launcher settings above.

Troubleshooting

  • Use Check link in the installer. It reads BepInEx\LogOutput.log and Minecraft's logs\latest.log.
  • Both sides must have the same ValCraft version, because the protocol changes between versions.
