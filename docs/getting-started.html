Getting Started

  1. Download ValCraft-Installer.exe and run it. It finds Valheim through Steam, installs BepInEx (from Thunderstore) and the ValCraft plugin, and sets up Minecraft (NeoForge 1.21.1). You can use your own Prism Launcher or a portable copy.
  2. Sign in with your Microsoft account when Prism asks. You only need to do this once.
  3. Open the ValCraft Launcher from the desktop or Start Menu. It checks GitHub for updates, verifies the downloads (SHA-256) and installs them.
  4. Click LAUNCH GAME. Valheim starts through Steam, and Minecraft starts with it when StartWithValheim is on.

Configuration

Settings are in BepInEx/config/dev.valcraft.valheim.cfg under [Minecraft]: StartWithValheim, Launcher (Prism / ATLauncher / Custom), PrismExe, InstanceName, ExtraArgs.

To repair or uninstall, run the installer again.
