FAQ

Windows SmartScreen warns about the installer or launcher

The executables are not code-signed. Choose More info → Run anyway. You can check them against the SHA256SUMS.txt file in each release.

The launcher says “Offline”

The launcher could not reach GitHub. It still shows the news it saved last time, and you can launch the game normally.

Where are the files installed?

The plugin goes to Valheim/BepInEx/plugins/ValCraft, the mod jar to your Prism instance's minecraft/mods, and the launcher to %LOCALAPPDATA%\Programs\ValCraft.

Minecraft doesn't start with Valheim

Check StartWithValheim and PrismExe in the plugin config, and make sure you signed in to Prism once.
